# Python While Loop Mastery

This repository contains practical solutions, exercises, and examples focused on mastering **`while` loops** and loop control structures in Python as part of the **Super30 Python Assignment Series**.

---

## 📌 Topics Covered

- **`while` Loop Fundamentals:** Condition evaluation, initialization, and counter updates.
- **Loop Control Statements:** Using `break`, `continue`, and `pass` inside `while` loops.
- **Infinite Loops & Sentinel Values:** Safe loop termination strategies and user-driven exit triggers.
- **Nested `while` Loops:** Grid structures, matrix traversal, and multi-variable iteration.
- **Input Validation:** Enforcing valid user input through dynamic retry conditions.

---

## 💻 Included Exercises & Concepts

1. **Basic Counter & Accumulator Patterns**
   - Summing numbers up to a specified limit $N$.
   - Print sequences (e.g., counting down, printing even/odd numbers).

2. **Loop Control Mechanisms**
   - Terminating execution early with `break` when meeting target conditions.
   - Skipping specific iterations using `continue`.

3. **Mathematical & Algorithmic Applications**
   - Digit manipulation (e.g., reversing digits of a number, calculating sum of digits).
   - Finding the Greatest Common Divisor (GCD) using the Euclidean algorithm with a `while` loop.
   - Fibonacci sequence generation using iterative state updates.

4. **Interactive User Prompts & Validation**
   - Requesting input repeatedly until valid boundaries or a sentinel value (e.g., `'quit'` or `-1`) is provided.
